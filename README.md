## Sobre mí

Soy desarrollador de software y capacitador en tecnología de Rosario, Santa Fe, Argentina.

Trabajo principalmente con **Java y Spring Boot** para APIs y sistemas backend; **React, Next.js y TypeScript** para aplicaciones web; y **Python** para automatización, procesamiento documental e inteligencia artificial aplicada.

Parte de mi experiencia se desarrolla en el ámbito de la economía social. Esto me permite combinar programación, análisis de procesos y conocimiento directo de los usuarios para crear herramientas que resuelven necesidades reales.

Actualmente me interesa seguir creciendo en desarrollo backend y Full Stack, automatización y transformación digital, sistemas RAG e inteligencia artificial generativa, testing, calidad de software y productos digitales con impacto social y educativo.

## Proyectos destacados

### 🤖 [TechRetAI](https://github.com/LeandroMelchiori/techretai_asistente_rag_corporativo)

Asistente corporativo basado en **RAG** que procesa documentación en ocho formatos, genera embeddings, recupera contexto con ChromaDB y responde mostrando sus fuentes.

Incluye proveedores intercambiables de Gemini y OpenAI, control por umbral de relevancia, logs, feedback, Docker y despliegue automático en OCI.

**Stack:** Python · RAG · Gemini · OpenAI · ChromaDB · Streamlit · Docker · OCI · GitHub Actions

[Ver demo](https://techretai.sachadev.me)

---

### 🧰 [Herramientas para Emprendedores](https://github.com/LeandroMelchiori/herramientas_para_emprendedores)

Suite web y PWA creada para acompañar la gestión cotidiana de emprendimientos.

Incluye calculadora de costos, registro de ventas, recursos de marketing digital, herramientas de identidad visual y biblioteca de prompts para IA.

**Stack:** JavaScript · HTML · CSS · PWA · Service Workers · jsPDF · Playwright

[Ver aplicación](https://economiasocial.sachadev.me)

---

### 🌱 [EcoSocial Backend](https://github.com/LeandroMelchiori/EcoSocial-BackEnd)

API para una plataforma de economía social que combina catálogo de productos, perfiles de emprendimientos y foro comunitario.

Implementa autenticación JWT, permisos, filtros, paginación, imágenes, migraciones, documentación OpenAPI y contenedores.

**Stack:** Java · Spring Boot · Spring Security · MySQL · Flyway · MinIO · Docker · JUnit

---

### ✅ [TaskFlow](https://github.com/LeandroMelchiori/React-ToDoList)

Aplicación local-first para organizar tareas, eventos, recurrencias, agenda y tableros de trabajo.

Funciona offline, utiliza IndexedDB, permite exportar información y cuenta con pruebas unitarias y end-to-end.

**Stack:** React · TypeScript · Vite · IndexedDB · PWA · Vitest · Playwright · GitHub Actions

---

### 🏟️ [Club Deportivo](https://github.com/UnknowTeam-TSDS/app_ClubDeportivo)

Aplicación Android de gestión para clubes deportivos.

Permite administrar clientes, socios, actividades, horarios, profesores, pagos, vencimientos y reportes mensuales.

**Stack:** Kotlin · Android · SQLite · Material Design

---

### 📚 [LiteraLura](https://github.com/LeandroMelchiori/literalura)

Aplicación de consola para consultar una API de libros, registrar autores y obras, y realizar búsquedas sobre una base de datos relacional.

**Stack:** Java · Spring Boot · PostgreSQL · JPA · API REST
